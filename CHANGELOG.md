# Spremembe

## 1.0

- Ime gradiva je **Učno gradivo**; osrednja datoteka je `SSJ_ucno_gradivo.md`.
- Številčna oznaka različice nadomešča datum v vlogi identifikatorja izdaje.
- Razlage in obdelani zgledi so zbrani v prvem delu, vaje pa v zadnjem delu po vsebinskem zaporedju predmeta.
- Dodane so izvirne pravopisne, besedotvorne in oblikoslovne vaje; ponovljene kopije so združene.
- Odstranjena so uredniška pojasnila o pripravi gradiva in povezovanju s preteklimi izpiti.
- Ohranjene so razlage in izrecno označene primerjave SP 2001 s predlogom Pravopisa 8.0.

## Začetno gradivo

- Prva objava: 6. oktober 2026.
- Deset razlagalnih poglavij, vaje, dva celostna preizkusa in pojasnjene rešitve.
